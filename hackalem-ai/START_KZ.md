# Іске қосу

1. ZIP архивін толық шығарыңыз. Архив ішінен Python файлын ашпаңыз.
2. VS Code → File → Open Folder арқылы осы `hackalem-ai` папкасын ашыңыз.
3. Python 3.12 немесе 3.13 және Ollama орнатулы болуы керек.
4. Нақты каталог үшін `START_EKT.cmd`, демонстрациялық каталог үшін
   `START_LOCAL_AI.cmd` файлын екі рет басыңыз.
5. Нақты каталог API логині мен паролін терминалда сұрайды.
   Парольді кодқа немесе GitHub-қа жазбаңыз.
6. Браузерде http://localhost:3000 ашылады. Тоқтату: терминалда Ctrl+C.

VS Code арқылы: Run and Debug ішінен `HackAlem` конфигурациясын таңдаңыз.
`start_ektsss.py` — `start_ekt.py` іске қосқышының балама атауы;
ол `start_local_ai.py` және жобаның басқа файлдарымен бірге тұруы керек.

Алғашқы іске қосуда Python кітапханалары мен AI моделі жүктеледі.
Нақты EKT API-ге кіру деректері қажет; корзина прототиптің өзінде сақталады.
