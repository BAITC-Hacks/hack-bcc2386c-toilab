РЕАЛЬНЫЙ КАТАЛОГ EKT.KZ

1. Остановите старые серверы: Ctrl+C в каждом терминале.
2. Дважды нажмите START_EKT.cmd.
3. На вопрос логина нажмите Enter.
4. Введите выданный пароль ekt.kz и нажмите Enter.
   При вводе пароль не виден — это нормально.
5. Дождитесь проверки API и запуска локальной модели.
6. Откроется сайт. Сначала может идти загрузка каталога.

Окно запуска не закрывайте. API-ключ ИИ не нужен, используется Ollama.
Если Ollama ещё не установлена, программа откроет официальный сайт установки.

Загружаются первые 2 страницы реальных товаров; это выборка.
Спросите в чате: Расскажи о товаре 200300285_, укажи цену, остаток и противоречия.

START_LOCAL_AI.cmd — прежний запуск с демонстрационными товарами.
Пароль в архив не включён и на диск не сохраняется.
Корзина принадлежит прототипу, не сайту ekt.kz. Оплаты нет.
