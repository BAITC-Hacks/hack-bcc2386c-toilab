Внутренняя схема проекта — три сервиса, один локальный чат.

Прототип-консультант поверх каталога ekt.kz. Работает как три независимых HTTP-сервиса на loopback-адресах; браузер видит только виджет чата.

Схема сервисов

Widget · :3000браузер, POST /assistant/message
Assistant · :8002tool loop, LLM, подтверждение
Catalog · :8001SQLite, поиск, корзина
Catalog синхронизируется с API партнёра (Basic Auth) только в режиме live. Открытие корзины — обычная ссылка на HTML-страницу Catalog, минуя Assistant.

Что где лежит

  • catalog-service/catalog/ — api.py маршруты, services.py правила, data.py SQLite, adapter.py поля партнёра, sync.py пагинация и снапшоты.
  • assistant-service/assistant/ — service.py ограниченный tool loop и may_execute, llm.py вызов модели, catalog_client.py HTTP-клиент.
  • chat-widget/public/ — интерфейс. Делает только один запрос: POST /assistant/message.
  • tests/ — модульные и контрактные тесты, запуск через run_tests.py.

Как запускать

Демо

START_LOCAL_AI.cmd — синтетический каталог, локальная модель qwen3:4b через Ollama, ключ не нужен.

Live

START_EKT.cmd — реальные товары ekt.kz, пароль запрашивается в терминале и нигде не сохраняется.
